# Contexto de Negócio

Este projeto simula uma operação de Marketing Analytics e CRM de uma empresa de telecomunicações.

A empresa deseja utilizar dados de clientes, consumo, recargas, faturas, interações e campanhas para:

- identificar clientes com risco de churn;
- localizar clientes pré-pagos inativos;
- criar audiências para campanhas;
- aplicar regras de consentimento;
- controlar a pressão de comunicação;
- avaliar campanhas anteriores;
- criar grupos de teste e controle;
- analisar conversão, receita e eficiência por canal;
- desenvolver modelos de propensão.

## Problema inicial

A primeira análise do projeto será direcionada à identificação de clientes pré-pagos que estão há mais de 30 dias sem realizar recarga.

Esses clientes poderão formar a audiência de uma campanha de reativação, desde que atendam às regras de consentimento e não tenham recebido campanhas recentemente.
